# HVR MAG - Верстка сайта

Верстка для сайта компании HVR MAG на основе дизайна из Figma.

## Структура проекта

```
hvr-mag-layout/
├── css/
│   └── style.css          # Основные стили
├── images/                # Изображения (нужно добавить)
├── index.html             # Главная страница
├── index2.html            # Страница стандартных серий
└── README.md             # Документация
```

## Структура страницы index.html

1. **Главный баннер** - Баннер с изображением и текстом "HVR MAG"
2. **Желтая информационная полоса** - Описание компании
3. **Секция продуктов** - 4 карточки с продуктами
4. **Информация о компании** - 4 параграфа о компании
5. **Особенности технологии** - Секция с изображением и описанием
6. **Желтый баннер** - Заголовок о преимуществах
7. **Безопасность** - 6 карточек безопасности + полноширинный текст
8. **Преимущества** - 7 карточек преимуществ
9. **Стандартные серии** - Секция с изображением и описанием

## Структура страницы index2.html

1. **Желтый баннер о решениях** - Информация о серийных и индивидуальных решениях
2. **Детальные стандартные серии НМ1-НМ5** - 5 серий с изображениями и описаниями
3. **Аккумуляторные серии** - 3 серии (НВЕР, НВЕРР, HBEPS) с изображениями
4. **Расширенная секция технологии** - Подробное описание технологии с диаграммами MAG/DEMAG PHASE

## Использование

1. Добавьте изображения в папку `images/`
2. Откройте HTML файлы в браузере
3. Для интеграции в проект скопируйте папку `hvr-mag-layout` в нужное место

## Цветовая схема

- Основной желтый: `#FFD700`
- Оранжевый для кнопок: `#FF8C00`
- Фон карточек: `#F5F5F5`
- Фон секций: `#F8F8F8`
- Текст: `#000`
- Белый фон: `#fff`

## Адаптивность

Верстка адаптивна и корректно отображается на:
- Десктопах (1200px+)
- Планшетах (768px - 1024px)
- Мобильных устройствах (< 768px)
